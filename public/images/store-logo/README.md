# مجلد شعار المتجر الرسمي / DeutschPlex Store Logo

يحتوي هذا المجلد على الهوية البصرية الرسمية لمتجر **DeutschPlex (دويتش بليكس)** وفق التصميم الجديد ثنائي اللغة (عربي وإنجليزي).

## مكونات الشعار:
- **الشارة الميكانيكية (Emblem)**:
  - صامولة سداسية كربونية مع 6 براغي تثبيت.
  - تروس داخلية ميكانيكية مطلية بالفضة.
  - قرص فرامل مهوّى مع ثقوب تبريد.
  - كليبر فرامل رباعي مع بطانات احتكاك حمراء قانية.
  - سرة محورية ميكانيكية برونزية بنجمة مسننة سداسية.
- **الطباعة ثنائية اللغة**:
  - `DeutschPlex` (Deutsch أسود فاحم + Plex أحمر قاني)
  - `دويتش بليكس` (دويتش أحمر قاني + بليكس أسود فاحم)
  - خط فاصل أنيق متناسق
  - `GENUINE GERMAN AUTO PARTS`
  - `قطع غيار اصلية للسيارات الألمانية`
