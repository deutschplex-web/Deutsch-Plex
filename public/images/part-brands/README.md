# Parts brand logos

Logos for the brands shown inside each category (ZF, Bosch, Bilstein and so on).

1. Put the file here, named in lowercase, e.g. `zf.svg`, `mahle-behr.png`.
2. Add it to `src/data/partBrandLogos.ts`, e.g. `'ZF': '/images/part-brands/zf.svg',`

Until a logo is added, the site shows the brand name in bold type instead.
SVG or a transparent PNG works best. Logos sit on a white tile.
