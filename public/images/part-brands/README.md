# Parts brand logos

Drop each brand's logo in this folder with the exact name below. No code change is needed: the site picks it up automatically.
Use `.svg`, `.png` or `.webp` (for example `zf.svg` or `zf.png`). A transparent background looks best, because logos sit on a white tile.

| --- | --- |
| ZF | `zf` |
| Sachs | `sachs` |
| LuK | `luk` |
| Bosch | `bosch` |
| VDO | `vdo` |
| Hella | `hella` |
| Aerosus | `aerosus` |
| Bilstein | `bilstein` |
| Lemförder | `lemforder` |
| Meyle | `meyle` |
| Febi | `febi` |

| Brembo | `brembo` |
| Mahle (Mahle Behr) | `mahle` |
| Pierburg | `pierburg` |
| Cohline | `cohline` |

Until a file is added, the tile shows the brand name in bold type.
The list lives in `src/data/partBrandLogos.ts`.
