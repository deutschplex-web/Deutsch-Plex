# مجلد الصور المستقبلية / Future Pictures Directory

هذا المجلد مخصص لحفظ صور السيارات، ورش الصيانة، قطع الغيار، والبنرات الإعلانية الحالية والمستقبلية لمتجر **DeutschPlex**.

## 📸 معايير الصور المستقبلية الموصى بها:
- **الصيغ المدعومة**: `.webp`, `.jpg`, `.jpeg`, `.png`. يُفضل استخدام `WebP` لأعلى كفاءة وسرعة تحميل.
- **الأبعاد المفضلة حسب الاستخدام**:
  - **صور الواجهة الرئيسية والبنرات (Hero & Banners)**: نسبة 16:9 بدقة 1920x1080 بكسل.
  - **صور بطاقات السيارات وقطع الغيار (Cards & Catalog)**: نسبة 4:3 بدقة 800x600 بكسل.
  - **الصور المربعة والرموز (Thumbnails)**: نسبة 1:1 بدقة 600x600 بكسل.
- **تسمية الملفات**: أحرف إنجليزية صغيرة ومفصولة بشرطة (مثال: `porsche-911-gt3-engine.jpg`).
