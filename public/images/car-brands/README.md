## إضافة ماركة جديدة:
1. ضع الشعار بصيغة SVG أو PNG بخلفية شفافة بدقة 512x512 على الأقل.
2. سمّ الملف باسم الماركة بالأحرف الصغيرة (مثال: `maybach.png`).
3. يتم ربطه تلقائياً في الكود عبر المسار `/images/car-brands/<filename>`.
